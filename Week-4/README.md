# Week 4 – Salesforce Administrator Track

## Overview

This week focuses on the core responsibilities of a Salesforce Administrator. The topics covered include user management, security, profiles, roles, permission sets, identity management, and enterprise access control. These concepts are essential for managing Salesforce users and protecting organizational data.

## Learning Objectives

- Understand the role of a Salesforce Administrator.
- Learn how to create and manage Salesforce users.
- Understand the differences between Profiles, Roles, and Permission Sets.
- Learn Salesforce Identity and Login concepts.
- Understand enterprise security and access control.
- Apply security concepts through practical exercises.
