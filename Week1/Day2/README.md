Day 2 - Salesforce Platform Basics

1. Salesforce Platform:
Salesforce Platform is a cloud-based platform used to build and manage business applications.
It provides tools to create apps, objects, fields, tabs, automation, reports, and custom features.

2. App in Salesforce:
An App in Salesforce is a collection of objects, tabs, and features used for a specific business purpose.
Example: College Management App

3. Object in Salesforce:
An Object is like a table in a database.
It stores a specific type of data.
Example: Student object stores student details like name, roll number, department, email, and phone number.

4. Tab in Salesforce:
A Tab is used to open and access an object in the Salesforce user interface.
Example: Student tab helps users view and manage student records.

5. Difference Between App and Object:
An App is a collection of objects and features.
An Object stores one type of data.
Example:
College Management App is an app.
Student is an object inside that app.

6. Multi-Tenant Architecture:
Multi-tenant architecture means many organizations use the same Salesforce infrastructure, but their data is kept separate and secure.
Example: Many companies can use Salesforce, but one company cannot see another company’s data.

7. Configuration:
Configuration means building or changing Salesforce using clicks instead of code.
Examples:
- Creating objects
- Creating fields
- Creating page layouts
- Creating reports
- Creating validation rules

8. Coding:
Coding is used when business requirements are complex and cannot be done only with configuration.
Examples:
- Writing Apex classes
- Creating API integrations
- Building Lightning Web Components
- Creating complex automation

9. Configuration vs Coding:
Configuration is used for simple changes that can be done using built-in Salesforce tools.
Coding is used for complex logic, external integrations, and custom features.

10. Day 1 and Day 2 Connection:
In Day 1, CRM concepts like Account, Contact, Opportunity, and Customer were learned.
In Day 2, it was understood that these concepts are managed in Salesforce using apps, objects, records, and tabs.
